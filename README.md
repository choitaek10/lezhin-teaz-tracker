# 레진 티즈 카운터

레진엔터테인먼트의 AI 캐릭터챗 **티즈(Teaz, https://myteaz.io/ko)** 공개 카운터를 매일 기록하는 대시보드입니다.
[탑툰챗 카운터](https://kjysss2.github.io/toptoonchat/)와 같은 구조(수집 스크립트 → JSON 누적 → GitHub Actions 예약 → GitHub Pages)로 만들었습니다.

## 무엇을 추적하나

| 탑툰챗 | 티즈 | 출처 |
|---|---|---|
| View | **좋아요** (`like_count`) | 홈 목록 응답의 방별 대표 캐릭터 |
| Chat | **메시지** (`message_count`) | 홈 카드에 보이는 숫자(예: `31.2K+`)의 정확한 값 |

- 티즈 홈은 브라우저가 공개 목록 `https://api.myteaz.io/chat/rooms?limit=50&sort=newest`를 로그인 없이 불러와 그립니다. 이 응답 하나에 모든 방(현재 19개)의 메시지·좋아요 수가 들어 있습니다. 그래서 작품 상세 페이지를 하나씩 열지 않고, **하루 1~2회 요청**으로 수집합니다.
- 한 방에 캐릭터가 여럿(2~4명) 있을 수 있습니다. 홈 카드와 같은 기준으로 **대표(입장) 캐릭터의 카운터**를 기록합니다.
- 현재 한국어(`/ko`) 서비스만 있어 국가 전환은 없습니다.
- 공개 카운터는 매출이나 실제 이용자 수와 같지 않습니다.

## 대시보드 구성

- 핵심 지표: 추적 작품 수, 누적 메시지·좋아요, 이전 수집 대비 순증, 데이터 기간
- 일별 순증, 누적 절대값, 주별·월별 순증. 메시지와 좋아요는 규모 차이가 커서(약 15만 대 900) 각각 따로 그립니다.
- **트랙션 모델**
  - 점유율: 전체 메시지 중 작품별 비중
  - 하루 평균: 누적 메시지 ÷ 활성 일수. 공식 출시일 2026-10-19 이전에 등록된 방은 출시일부터 셉니다. 베타 기간 메시지가 섞일 수 있는 추정치입니다.
  - 최근 순증: 직전 수집 대비 메시지 증가를 하루 기준으로 환산한 값
- 작품 표: 정렬, 검색(이름·태그), 좋아요/1천 메시지, 등록일
- 열어 두면 1분마다 데이터를 다시 읽습니다.

## 자동 업데이트

- 매일 **07:00 KST**에 실행합니다. 지연에 대비해 07:17, 07:37, 08:07, 09:07에도 예약해 두었습니다. 그날 07:00 이후 정상 수집이 이미 있으면 건너뜁니다.
- 수집에 실패하면 기존 파일을 덮어쓰지 않습니다. 작품이 5개 미만으로 읽혀도 실패로 처리합니다.
- GitHub Actions 예약 실행은 정시를 보장하지 않습니다.

## GitHub에 올리기

1. 새 공개 저장소를 만들고 이 폴더 내용을 `main` 브랜치로 push합니다.
2. **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
3. **Actions → Capture Lezhin Teaz counters → Run workflow**로 첫 실행을 합니다. 오늘 이미 수집한 값을 다시 받으려면 **force**를 체크합니다.
4. 사이트는 `https://<계정>.github.io/<저장소>/`에 열립니다.
